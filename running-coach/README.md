# Stride — Coach course local

Application locale de suivi et de programmation running. Elle ne modifie aucun module TAF OPS.

## Lancer

Ouvrir `index.html` dans un navigateur. Aucun serveur ni installation n’est nécessaire.

## Version MVP

- tableau de bord visuel avec charge, forme et repères de performance ;
- programme hebdomadaire explicable ;
- import local CSV/GPX/JSON ;
- stockage navigateur via `localStorage` ;
- aucune donnée envoyée vers un serveur.

La prochaine itération remplacera les données de démonstration par le parseur Strava et le moteur d’analyse personnalisé.
