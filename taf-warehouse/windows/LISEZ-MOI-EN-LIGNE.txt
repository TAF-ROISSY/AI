TAF WAREHOUSE — lanceur Windows (application en ligne)
=====================================================

Contenu
-------
  TAF WAREHOUSE.exe              Ouvre TAF WAREHOUSE dans sa propre fenêtre (comme un logiciel).
  TAF WAREHOUSE - Poste quai.exe Même chose, avec IMPRESSION DIRECTE : les étiquettes, fiches et
                                 récapitulatifs partent sur l'imprimante par défaut sans fenêtre
                                 d'impression. À utiliser sur le PC dédié du quai.

Installation
------------
1. Décompressez le dossier, par exemple dans « Documents » ou « C:\TAF ».
2. Clic droit sur « TAF WAREHOUSE.exe » > Envoyer vers > Bureau (créer un raccourci).
3. Double-cliquez : l'application s'ouvre. Connexion : prénom ou e-mail + code PIN.

Ce lanceur n'installe rien : il utilise Microsoft Edge (présent sur Windows 10 et 11) ou Google Chrome.
Les données restent sur le serveur TAF (AWS Paris) : tous les postes voient les mêmes informations.

Poste quai (impression directe)
-------------------------------
- Réglez l'imprimante voulue comme « imprimante par défaut » de Windows
  (Paramètres > Bluetooth et appareils > Imprimantes).
- Fermez toutes les fenêtres TAF WAREHOUSE avant d'ouvrir la version « Poste quai ».
- Pour les étiquettes 80 x 130, réglez le format papier du pilote de l'imprimante thermique.

Au premier lancement, Windows peut afficher « Windows a protégé votre ordinateur » (programme
non signé) : cliquez sur « Informations complémentaires » puis « Exécuter quand même ».
